# madkhandez.github.io — Portfolio Website

Personal portfolio website for **Madkhan Kamal** — Senior Software Engineer specializing in AI/ML, RAG architectures, and backend systems.

🌐 **Live at**: [madkhandez.github.io](https://madkhandez.github.io)

## Tech Stack

- **HTML5** — Semantic, SEO-optimized structure
- **CSS3** — Custom properties, glassmorphism, animations, responsive design
- **Vanilla JavaScript** — Typing effects, scroll animations, particle background, project filtering
- **Google Fonts** — Inter + JetBrains Mono
- **Font Awesome** — Icon library
- **Formspree** — Contact form backend (free tier)

## Features

- 🌙 Premium dark theme with glassmorphism
- ✨ Canvas particle animation background
- ⌨️ Typing effect hero section
- 📊 Animated skill progress bars
- 🔄 Project filtering by category
- 💬 Testimonials carousel
- 📱 Fully responsive (mobile-first)
- 🔍 SEO optimized with meta tags

## Deploy to GitHub Pages

1. Create repository `madkhandez.github.io` on GitHub
2. Push this code:

```bash
cd madkhandez.github.io
git init
git add .
git commit -m "Initial portfolio website"
git branch -M main
git remote add origin https://github.com/madkhandez/madkhandez.github.io.git
git push -u origin main
```

3. Go to **Settings → Pages → Source: main branch** → Save
4. Your site will be live at `https://madkhandez.github.io`
